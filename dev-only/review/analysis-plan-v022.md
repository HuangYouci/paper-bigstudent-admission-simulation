## H8　紀錄的最後更新時間

`input.sourceUpdatedAt` 是使用者文件的最後更新時間（可能因成績、志願或其他欄位更新而改變），故「早於截止」表示輸入在截止前已定，「晚於截止」只表示可能在截止後修改。報告：評估梯次有效紀錄中，最後更新早於、晚於登記截止（2026-08-08 16:30 臺灣時間）與缺值的筆數；以假名比對評估梯次與截止前最後一個梯次（`ast_20260808T035958Z`）的同一使用者，輸入完全相同、不同、僅出現在其中一方的筆數。

以目前 v3 規則（三帶校準、起始 39,213、Fractional DA、v3 內插）重跑 8 個保存梯次各自的輸入，並另建「截止時重建樣本」：取截止後最早梯次（`ast_20260808T095000Z`）中最後更新早於截止的紀錄，最後更新晚於截止者以截止前梯次（`ast_20260808T035958Z`）的版本代替（無則剔除）。

主要估計：截止前最後完成的梯次 `ast_20260808T035958Z`（4,242 文件，臺灣時間 12:01 完成）。在 $\mathcal J_2$ 上報告：與基準以固定 $\lambda=0.4$ 組合的 MAE（該梯次無 v3 值之校系以基準代替）減基準 MAE 及其群聚區間與相對差；有 v3 值之校系的 v3 MAE；正式門檻高於預測至少一級的比例；$\delta=1$ 的方向一致率。次要：其餘 7 個梯次、截止時重建樣本、評估梯次中最後更新早於截止的子集。
