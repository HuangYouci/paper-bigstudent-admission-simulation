# v0.18 新增分析之事前規格：模擬本身的不確定性

撰寫時間：2026-10-12（臺灣時間），在讀取會員資料、執行重抽之前寫定。

## H6　考生重抽的模擬不確定性

目的：回應「學校群聚區間只反映校系組成，未反映換一批考生」的審查意見。

程序：自去鏡射 4,627 筆記錄有放回重抽 4,627 筆（重複抽中者以不同代碼視為獨立記錄），每次重新以正式 3 帶規則校準（起始 39,213、容差 0.001、上限 2,000 輪），以 Fractional DA 與 v3 內插產生門檻。重抽 B = 200 次，亂數種子 20261012（mulberry32）。

報告：
1. 各校系 v3 門檻的 5%／50%／95% 分位（僅校系層級）；以倍率標準化的 90% 區間寬度中位數。
2. 每次重抽在 $\mathcal J_2$ 上的 v3 MAE、與基準 0.4 混合的 MAE、混合減基準之差、δ=1 方向一致率；報告 2.5%／97.5% 分位，以及混合差 < 0 的比例。
3. 官方門檻落在該系 90% 重抽區間內的校系比例（覆蓋率；描述性，非校準檢驗）。

解讀界線：重抽只反映「平台內樣本」的變異，無法反映自選機制或志願偏差；不改變主要結果的點估計。
